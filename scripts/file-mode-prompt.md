# 落盘模式（note-offload）首句参考

> 本规范已封装为全局技能 `~/.gemini/config/skills/note-offload/SKILL.md`。
> 日常新开会话时，直接一句即可激活，无需复制长模板：
>
> `用 note-offload 落盘模式接续 <任务一句话>，只做一件事：<具体动作>`

默认会话仍为普通模式。仅在需要大输出、长日志/反汇编分析，或旧会话连续受限后接续时启用**落盘模式**。

## 手动首句备用模板

```text
接续 <任务一句话>。[落盘模式] 正文只留一行（结论 + 路径，120 字内），详细内容全部写入
~/agy-notes/<会话前8位>/turn-N.md；读大文件用 grep 定位 + sed 取行，不要整份 cat。

只做一件事：<具体动作>
```

## 单步收窄三条

1. 一次只处理一个函数、接口或独立子问题；
2. 命令大输出先重定向到落盘目录再提炼，正文只报一行；
3. 完成一条结论后，把笔记路径留给下一轮或新会话，不在单会话内无限堆步数。
